# 캐릭터 스탯

## 🎭 캐릭터 스탯 (Character Stats)

캐릭터의 기초 능력치입니다. 모든 판정의 근간이 됩니다.

#### 기초 수치

> **❤️ 체력 (HP)**: 생존 수치입니다. 0이 되면 행동 불능이 됩니다.&#x20;
>
> **⚡ 스테미나 (SP)**: 활동 에너지입니다. 0이 되면 피로 상태가 됩니다.

***

#### 주 능력치 (Main Stats)

* **✊ 힘 (STR)**: 물리적인 근력과 공격력을 담당합니다.
* **🛡️ 건강 (CON)**: 상태이상 내성과 체력/스테미나 증가를 담당합니다.\[cite: 1]
* **🏃 속도 (SPD)**: 회피와 전투 턴 순서에 영향을 줍니다.\[cite: 1]
* **🎯 정밀 (PRE)**: 명중률과 원거리 공격의 이점을 담당합니다.\[cite: 1]
